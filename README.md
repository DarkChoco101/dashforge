# DashForge 🚗

Customizable car dashboard for Android tablets: 11 skins, a drag-and-drop editor, OBD2 (ELM327 BLE), GPS trips with route maps, a performance timer, alerts, fault codes, and a media dock (YouTube + app launcher).

- **Web app / install on tablet:** https://darkchoco101.github.io/dashforge/ (open in Chrome → menu → Install app)
- **Android APK:** see [Releases → latest](../../releases/tag/latest)

## Develop
Edit files in `src/`, then run `python3 build.py` → `www/index.html`. Pushing to `main` deploys the web app and builds the APK automatically.
